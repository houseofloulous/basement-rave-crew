# Basement Rave Crew

Static browser game for the Brooklyn club basement crew.

## Play locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

On macOS you can also double-click `START-ON-MAC.command`.

## Notes

Built with GDevelop. No server required for single-player local play.
