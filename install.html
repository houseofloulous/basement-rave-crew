Install the real club

Basement is being built as a GTA: San Andreas map — the same medium as the club recreations that actually look like Basement (not the browser prototype).

  1. Get GTA: San Andreas on PC (Steam / classic). Use a copy you’re willing to mod.
  2. Install ModLoader (+ ASI loader) so packs drop in without nuking the base game.
  3. Install Ariane if you’re helping build the map (gtastuff.com/ariane).
  4. When the pack ships, copy modloader/BasementRaveCrew/ into your game’s modloader folder and launch SA.
