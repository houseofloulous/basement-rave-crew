Mad Max Crew · Mac

Install the real club

No Windows PC needed. The club that matches the reference reel is a GTA: San Andreas map — on Mac you run SA inside CrossOver (Whisky is flakier).

On your Mac

  1. Install CrossOver (CodeWeavers). Trial is fine to try the game.
  2. Install Steam inside CrossOver, then buy/install GTA: San Andreas.
  3. Downgrade to SA v1.0 + SilentPatch + ASI loader + ModLoader (same stack Mac gamers use for classic SA).
  4. When our pack ships, drop modloader/BasementRaveCrew/ into the game’s modloader folder and launch from Steam in CrossOver.

Building the map

Map editing uses Ariane against that same SA install. Layout + crew roster live in gta-sa-mod/ on GitHub while the pack is scaffold-only.

The browser walkthrough is a temporary prototype — use it to poke around until the Mac SA pack is playable. Details: BUILD-PIVOT.md
