# Basement on Roblox (Mac, free)

No CrossOver. No paid Windows layer. Roblox Studio + a free Roblox account.

## Why this path

- Free on Mac  
- Built-in multiplayer + custom avatars (each of you is your own character)  
- Looks like an actual 3D game, not the crude browser sketch  
- We can match Basement layout: courtyard → gate → ramp → tunnel → security → floors  

## Checklist

### A. Account
- [ ] Create a free account at [roblox.com](https://www.roblox.com)
- [ ] Install **Roblox** (to play) and **Roblox Studio** (to build) from the Mac download / App Store flow Roblox shows you

### B. Studio
- [ ] Open Roblox Studio → New → Baseplate (or a warehouse template if you prefer)
- [ ] Save the place as **Basement Rave Crew** (File → Publish to Roblox) — keeps it in your account for free

### C. Build order (we’ll drive this together)
1. Courtyard + brick walls + gate  
2. Ramp / tunnel  
3. ID + fashion check  
4. Lockers → main / Charlotte → studio → dark rooms → bathrooms → backyard  
5. Lighting (red wash, industrial)  
6. Crew spawn points + outfit tips (Mad Max / harness)

### D. Play with friends
- [ ] In Roblox.com place settings: allow friends (or public when you’re ready)
- [ ] Share the Roblox place link (Bitly that if you want a pretty URL)
- [ ] Everyone opens Roblox on Mac/phone and joins
